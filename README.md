# Site de Eletronica

Este repositório contém a aplicação web, mídias e materiais de referência para o projeto **Site de Eletronica**.

## Estrutura do Repositório

- **`timefest/`**: Aplicação Web desenvolvida com React 19, Vite, GSAP e Lenis Scroll.
- **`Para o site/`**: Mídias, sequências de imagens e assets gráficos do projeto.
- **`Refências/`**: Imagens de referência e identidade visual.

## Como Rodar o Projeto Web

1. Navegue até a pasta da aplicação:
   ```bash
   cd timefest
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
